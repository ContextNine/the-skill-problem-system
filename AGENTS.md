# Agent instructions

This repository contains the Skill Problem System. Read `README.md` for installation and `edit/README.md` to find editable source files.

Before creating or reorganizing a skill, read `edit/skills/_agents/agents-i-write-or-edit-a-skill/SKILL.md`. Keep authored skills under `edit/skills/`, user settings under `edit/settings/`, and generated files out of source control. Do not store credentials in this repository.
