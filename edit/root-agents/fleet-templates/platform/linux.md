## Platform context

This machine runs Linux. User-installed fleet commands and portable skill snapshots live below the home directory. Vault availability and checkout policy come from the machine registry, not the operating system.

The Codex Browser plugin runtime is unavailable on Linux code workers. Use the installed `playwright-cli` for browser-based visual and interactivity QA instead. When that QA is within the requested task, proceed without asking permission to make this substitution.
