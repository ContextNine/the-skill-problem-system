# Agents · Write project instructions

In a given repo, the README.md is meant for humans to understand succinctly whether or not they want to use this repo. 

The AGENTS.md or CLAUDE.md should describe how to update code and what to know before doing that for agents. 
A glossary section is often useful for a common domain language. 


Use `references/` for examples of concise READMEs and agent instructions. Read `references/global-instructions.md` when changing global instructions or their fleet variants. The shared template contract is owned by `$agents-i-write-or-edit-a-skill` in `references/fleet-templating.md`.
