## Kimi Code

Dependency ID: `kimi-code`. It is an optional coding tool installed only when selected for the target. Use the official checksum-verifying installer, preserve its detected executable ownership, and verify the installed version before acceptance.

Provider login is a target-local interactive ceremony covered by machine-local-secrets-and-enrollment. Never copy OAuth state between machines. Updates remain on the approved official channel; recovery reinstalls through the same channel, and removal is separately authorized.
