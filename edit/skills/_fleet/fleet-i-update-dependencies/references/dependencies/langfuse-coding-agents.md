## Langfuse coding-agent integration

Dependency ID: `langfuse-coding-agent-integration`. This optional service is selected explicitly and managed through fleet-configure-langfuse-coding-agents. Node 24, uv, and the selected coding tools are prerequisites.

The distributed scaffold contains only non-secret instance metadata and remains disabled without approved native credential custody. Enrollment, test-trace verification, rotation, and recovery follow setup-and-enrollment. Never place API keys or authorization headers in synchronized JSON, TOML, settings, or shell profiles.
