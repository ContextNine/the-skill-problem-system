## Codex CLI

Dependency ID: `codex-cli`. It is required on enabled agent machines and consumed by onboarding, configuration/plugin reconciliation, and infra-i-update-fleet-coding-tools. Preserve the detected installation provenance and executable owner; do not silently replace a native, npm, Homebrew, or application-bundled installation with another channel.

Routine sync verifies or installs only through the approved adapter. Fleet update records before/after executable and version evidence and does not copy login state. Login is target-local and follows machine-local-secrets-and-enrollment. Recovery restores the prior proven installation method; removal must not delete Codex task history or app data.
