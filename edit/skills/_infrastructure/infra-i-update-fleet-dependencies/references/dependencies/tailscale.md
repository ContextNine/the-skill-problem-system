## Tailscale

Dependency ID: `tailscale`. It is installed only when selected in the machine registry. [[tailscale-machine-access]] owns the official signed macOS package or reviewed Linux package path, desired node settings, authentication checkpoint, and acceptance.

Account choice, login, MFA, VPN approval, and Terms checkpoints remain user actions. Tailscale SSH stays disabled; regular OpenSSH is the fleet identity. Verify provider status and a new inbound SSH connection. Device retirement and uninstall require separate authorization.
