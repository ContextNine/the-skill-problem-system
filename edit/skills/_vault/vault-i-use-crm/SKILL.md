# Vault · Use CRM

Use `$vault-i` to locate the Vault and follow its access and Git rules. Read GTM template completely.

Read README-crm, use `$witan-xlsx`, and change only the selected company's `gtm/CRM.xlsx`. Never create a companion contact note or write the same record to another company's workbook.

Follow the selected guide for the teamspace and record. Keep reusable operating rules in the guides, not in this skill.

For setup or a structural migration, read `references/setup-crm.md`.
