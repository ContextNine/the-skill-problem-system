# Machine Requirements And Topology

Config paths beginning with `./fleet/`, `./skills/`, or `./dependencies/` are relative to the directory returned by `fleet config path`.

Generic machine roles, registry rules, and safe sync behavior live in `../README-primary-worker-vault-sync.md`. Use `$fleet-i-onboard-machine` for machine mutation and acceptance.

Private current fleet observations, personal paths, addresses, installed versions, and operational history live in `./skills/config/fleet-i-code-folder-and-computer-topology/private/fleet-observations.md`. Read config README before using them and rediscover mutable facts before changing remote machine.
