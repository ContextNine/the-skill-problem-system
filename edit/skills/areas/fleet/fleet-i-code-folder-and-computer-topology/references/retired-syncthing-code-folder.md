# Retired Syncthing Code Folder

Config paths beginning with `./fleet/`, `./skills/`, or `./dependencies/` are relative to the directory returned by `fleet config path`.

Generic recovery rule: keep retired replication disabled, inspect preserved source read-only, and recover wanted work into fresh Git clones.

Private retirement dates, machine paths, backups, and snapshots live in `./skills/config/fleet-i-code-folder-and-computer-topology/private/retired-syncthing-code-folder.md`.
