## macOS prerequisites

Dependency IDs: `homebrew` and `xcode-command-line-tools`. Onboarding owns their protected installation checkpoints. Homebrew location is architecture-dependent and comes from the machine registry or detected installation, never a hard-coded personal path.

Verify `brew --version`, developer-tool selection, compiler availability, and ownership before package reconciliation. Major Xcode, macOS, or Homebrew migrations are outside routine fleet update. Recovery follows the official installer and preserves existing package state; removal is separately authorized.
