# Operations

Resolve bundled file paths relative to this document; run its command examples from this directory and resolve project inputs against the target project.

The audit writes private evidence to `${XDG_STATE_HOME:-$HOME/.local/state}/ctx9-automation/cluster-wizard`. It checks nodes, workload readiness, warning events, certificates, CNPG, backups, Longhorn, CSI, ingress, resource pressure, and stuck jobs.

```bash
python3 ../scripts/audit.py run --audit-only
python3 ../scripts/install-systemd.py install
python3 ../scripts/install-systemd.py status
python3 ../scripts/install-systemd.py run-once
python3 ../scripts/install-systemd.py disable
python3 ../scripts/install-systemd.py uninstall
```

The timer is persistent and runs at midnight in `Africa/Johannesburg`. A healthy audit performs no LLM call.
