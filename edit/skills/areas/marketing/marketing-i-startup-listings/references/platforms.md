# Candidate platforms

This is a seed catalog, not verified eligibility, pricing, submission routes or backlink attributes. Open the platform's current website before each attempt. The tracker uses the stable IDs below. Add niche platforms when they match the product; avoid expanding the queue merely to collect domains.

| ID | Platform | Website | Fit to check |
|---|---|---|---|
| chrome-web-store | Chrome Web Store | https://chromewebstore.google.com/ | An actual Chrome extension, developer account and publishing assets; check for an existing extension listing. |
| medium | Medium | https://medium.com/ | Useful original content and a relevant profile; publishing articles is separate work from creating a profile. |
| product-hunt | Product Hunt | https://www.producthunt.com/ | Product launch readiness, existing product page and approved launch timing. |
| trustmrr | TrustMRR | https://trustmrr.com/ | Revenue verification and deliberate public disclosure; connecting a payment provider needs explicit authorization. |
| openalternative | OpenAlternative | https://openalternative.co/ | A qualifying open-source product and repository. |
| alternativeto | AlternativeTo | https://alternativeto.net/ | Accurate software categories and genuine alternatives; search for an existing entry. |
| uneed | Uneed | https://www.uneed.best/ | Relevant product category, current listing options and costs. |
| github-pages | GitHub Pages | https://pages.github.com/ | Hosting useful project documentation/content; choose a real content purpose before creating a site. |
| forbes | Forbes | https://www.forbes.com/ | Editorial coverage or a qualifying membership route; route to PR research rather than generic directory signup. |
| trustradius | TrustRadius | https://www.trustradius.com/ | Software category fit, vendor listing/claim process and authentic reviews. |
| sourceforge | SourceForge | https://sourceforge.net/ | Appropriate software business listing or open-source project route. |
| peerlist | Peerlist | https://peerlist.io/ | Product/project showcase and founder identity. |
| indie-hackers | Indie Hackers | https://www.indiehackers.com/ | Current product/profile features and community promotion rules. |
| betalist | BetaList | https://betalist.com/ | Product stage eligibility, current submission queue and costs. |
| dev-hunt | Dev Hunt | https://devhunt.org/ | Developer-tool fit and approved launch timing. |
| indie-page | Indie Page | https://indiepa.ge/ | Founder/startup profile, current service availability and listing options. |
| saashub | SaaSHub | https://www.saashub.com/ | Software/alternative discovery, existing entry and current submission process. |
| linkedin-person | LinkedIn personal profile | https://www.linkedin.com/ | Existing professional identity and website field; preserve unrelated profile information. |
| github-profile | GitHub profile | https://github.com/ | Existing developer identity and website field; do not create a redundant repository for a link. |
| linkedin-company | LinkedIn company page | https://www.linkedin.com/ | Existing company page, admin rights, accurate service positioning and canonical website. |
| clutch | Clutch | https://clutch.co/ | Service-business profile, current free offer and accurate business details. |
| goodfirms | GoodFirms | https://www.goodfirms.co/ | Service categories, existing company profile and free submission route. |
| designrush | DesignRush | https://www.designrush.com/ | Agency/service fit, current listing costs and submission requirements. |
| the-manifest | The Manifest | https://themanifest.com/ | Check whether the company entry is populated through Clutch before submitting separately. |
| google-business | Google Business Profile | https://www.google.com/business/ | Confirm in-person customer-contact eligibility before starting a service-business profile. |
| g2 | G2 | https://www.g2.com/ | Category eligibility, existing profile and vendor claim process. |

Rank free, suitable listings with a reachable audience ahead of paid placement or elaborate content work. An ineligible startup can skip a platform with a recorded reason. Unknown eligibility stays unknown until checked. Inspect existing listings as the baseline before assuming any startup has zero backlinks.

For current platform requirements, consult the official [Chrome publishing guide](https://developer.chrome.com/docs/webstore/publish), [OpenAlternative description](https://openalternative.co/about), [TrustMRR FAQ](https://trustmrr.com/faq), [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [Forbes Councils qualifications](https://councils.forbes.com/qualify), and [G2 listing documentation](https://documentation.g2.com/help/docs/finding-or-listing-a-product-on-g2). DR terminology is defined by [Ahrefs](https://ahrefs.com/seo/glossary/domain-rating).
